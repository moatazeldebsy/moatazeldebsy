# 👋 Hi, I'm Moataz Nabil

I’m the author of [*Mobile DevOps Playbook*](https://www.amazon.com/Mobile-DevOps-Playbook-accelerating-high-quality/dp/1803242558/ref=sr_1_1?keywords=9781803242552&tag=packtpub-20), an engineering leader, and a technology content creator.

I focus on building scalable **Internal Developer Platforms (IDPs)**, improving developer experience, and empowering high-performing engineering teams. I specialize in platform architecture, DevOps, mobile DevOps, test automation, and cloud technologies.

> Great platforms empower great engineers—and sustainable, developer-centric solutions are key to lasting success.
